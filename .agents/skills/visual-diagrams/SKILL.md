# Visual Diagrams

- Maak alleen een schema als relaties duidelijker worden dan een tabel of één alinea.
- Kies de juiste vorm: architecture, dataflow, decision tree, state machine, timeline, sequence of dependency graph.
- Haal brandingtokens uit het bestaande project; 1 of 2 accentpunten, ruimte en leesbare typografie.
- Voor losse visuals eerst een zelfstandig HTML-bestand met inline SVG, zonder framework en zonder buildstap.
- Houd labels direct bij relaties, weinig kruisende lijnen, consistente pijlen en een werkende legenda indien nodig.
- Test breed én smal; respecteer contrast en toegankelijkheid. Motion alleen met functie en reduced-motion fallback.
- Als de gebruiker wil aanpassen: maak onderliggende labels/nodes eenvoudig bewerkbaar, geen onnodige codegenerator.

Voorbeelden: GitHub naar hosting, APK-releaseflow, Excel naar Python naar Power BI.

Bronideeën: Diagram Design.
